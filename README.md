# NeuroGuia

Protótipo funcional da interface do **NeuroGuia** — assistente educacional com avatar interativo **OLLIE** desenvolvido para apoiar estudantes neurodivergentes do PPGEC/UPE.

## Pré-requisitos

- [Node.js](https://nodejs.org/) 18 ou superior
- npm (incluído com o Node.js)

## Como executar

```bash
# Clone o repositório
git clone https://github.com/FHPA-UPE/NeuroGuia.git
cd NeuroGuia

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

## Sobre o protótipo

Esta versão contempla a camada de UX e UI do avatar OLLIE:

- **Identidade Visual** — design do avatar com expressões faciais distintas
- **Movimentação** — estados de repouso, comunicação e pensamento
